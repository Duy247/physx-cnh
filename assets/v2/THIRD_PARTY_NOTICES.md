# Bundled third-party browser assets

- **Mozilla PDF.js 6.2.108** — Apache License 2.0. The upstream license is retained at `pdfjs/LICENSE`.
- **Three.js r180** — MIT License. The upstream license header is retained in both bundled modules.
- **GoJS 4.0.3 evaluation build** — proprietary evaluation license. Its evaluation notice remains visible by design; see <https://gojs.net/4.0.3/license.html>.
- **Be Vietnam Pro** and **Geist Mono** — SIL Open Font License 1.1. The font files are served locally and are not requested from a third-party CDN.

These files are versioned with the site so the Hostinger deployment has no runtime CDN dependency.
